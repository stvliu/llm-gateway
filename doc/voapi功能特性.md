## 一、项目概述

### 1.1 项目定位
VOAPI是基于NewAPI和OneAPI二次开发的全新高颜值、高性能AI模型接口管理与分发系统，采用Go语言开发，专注于为企业级用户提供一站式的AI API网关解决方案。

### 1.2 核心价值
- **统一API聚合**：聚合20+主流AI模型API，提供标准化接入点
- **智能成本控制**：Token消耗统计、成本监控和优化
- **企业级高可用**：自动故障转移、负载均衡和性能监控
- **完善多租户**：完整的用户管理、权限控制和运营体系
- **商业就绪**：支付、发票、认证等完整商业化功能

### 1.3 技术特性
- **开发语言**：Go 1.19+，原生高并发支持
- **数据库**：MySQL 5.7+（必需）+ Redis 6.0+（必需）
- **部署方式**：Docker Compose一键部署
- **资源要求**：最低1C1G服务器配置
- **开源协议**：Apache-2.0

## 四、技术规格

### 4.1 系统要求
- **最低配置**：1C1G服务器即可流畅运行
- **推荐配置**：2C4G以上获得最佳性能
- **数据库**：MySQL 5.7+/PostgreSQL 12+/ClickHouse
- **缓存**：Redis 6.0+

### 4.2 部署规格
```yaml
# 配置文件示例
app:
  port: 6800  # 默认端口
db:
  dirver: mysql  # 支持mysql, pg
  log-dirver: mysql  # 支持mysql, pg, clickhouse
mysql:
  dsn: root:@tcp(db-voapi:3306)/voapi
  log-dsn: root:@tcp(db-voapi:3306)/voapi-log
  log-body-dsn: root:@tcp(db-voapi:3306)/voapi-body-log
redis:
  dsn: redis://redis-voapi:6379/0
  pool-size: 0  # 0表示使用默认值(CPU数量*100)
```

### 4.3 性能指标
- **并发支持**：1000+并发请求
- **响应时间**：API转发延迟<100ms
- **可用性**：99.9%以上
- **扩展性**：支持水平扩展
