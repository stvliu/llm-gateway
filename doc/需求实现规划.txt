实现阶段规划

Phase 1: 基础设施 (Foundation) — 安全零信任

1.1 数据库Schema → 1.2 JPA实体 → 1.3 API Key加密 → 1.4 认证鉴权 → 1.5 限流

关键文件:
- db/migration/V1__initial_schema.sql — 核心表结构（含审计字段）
- ModelProvider.java, GatewayApiKey.java, User.java — 实体类
- GatewayApiKeyEncryptionService.java — AES-256 加密
- GGatewayApiKeyAuthenticationFilter.java — 认证过滤器
- RateLimitService.java — 令牌桶限流

Phase 2: API端点 (Dual API Compatibility) — 核心价值

2.1 OpenAI控制器 → 2.2 Anthropic控制器 → 2.3 协议转换服务 → 2.4 Web层DTO

关键文件:
- OpenAIController.java — /v1/chat/completions
- AnthropicController.java — /v1/messages
- TranslationService.java — OpenAI ↔ Anthropic 双向转换

验收标准: SC-001/002/003 (API兼容性和转换准确率)

  ---
Phase 3: 路由与预算 (Routing & Budget)

3.1 ModelRouter → 3.2 TokenTracking → 3.3 BudgetEnforcement

关键文件:
- ModelRouter.java — 智能路由（PRIORITY/COST_OPTIMIZED/LATENCY_BASED）
- TokenTrackingService.java — 输入/输出Token精确计量
- BudgetEnforcementService.java — 四级预算控制
