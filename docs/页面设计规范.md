## 四、实体列表点击交互规格

### 4.1 核心交互：点击列表行打开抽屉详情

#### 交互流程图

```
用户点击列表行
      │
      ▼
┌─────────────────────────────────────┐
│  检查当前是否有未保存的编辑更改     │
└─────────────────────────────────────┘
      │
      ├──── 有未保存更改 ────┐
      │                      ▼
      │           ┌─────────────────────────────┐
      │           │  弹出确认对话框             │
      │           │  "您有未保存的更改..."      │
      │           └─────────────────────────────┘
      │                      │
      │                      ├──── [继续编辑] ──── 保持当前抽屉，不切换
      │                      │
      │                      └──── [放弃更改] ──── 关闭当前抽屉，打开新抽屉
      │
      └──── 无未保存更改 ────┐
                            ▼
                 ┌─────────────────────────────┐
                 │  关闭当前抽屉（如有）       │
                 │  打开新实体详情抽屉         │
                 │  高亮选中行                 │
                 └─────────────────────────────┘
                            │
                            ▼
                 ┌─────────────────────────────┐
                 │  加载实体详情数据           │
                 │  显示详情内容               │
                 └─────────────────────────────┘
```

#### 点击区域定义

| 点击区域 | 触发行为 | 说明 |
|----------|----------|------|
| **行内任意单元格** | 打开详情抽屉 | 除操作列外的所有区域 |
| **操作列图标按钮** | 执行对应操作 | 编辑、删除等，不打开抽屉 |
| **复选框列** | 切换选中状态 | 用于批量操作，不打开抽屉 |
| **行内链接/按钮** | 执行链接/按钮操作 | 如名称列可点击链接 |

#### 点击事件处理

```typescript
interface TableRowClickHandler {
  // 点击行事件
  onRowClick(event: MouseEvent, row: Entity, rowIndex: number): void {
    // 1. 判断点击目标
    const target = event.target as HTMLElement;
    
    // 排除：复选框、操作按钮、链接
    if (this.isExcludedElement(target)) {
      return;
    }
    
    // 2. 检查未保存更改
    if (this.hasUnsavedChanges) {
      this.showUnsavedConfirmDialog().then(confirmed => {
        if (confirmed) {
          this.openDetailDrawer(row, rowIndex);
        }
      });
    } else {
      // 3. 直接打开抽屉
      this.openDetailDrawer(row, rowIndex);
    }
  }
  
  // 判断是否为排除元素
  isExcludedElement(target: HTMLElement): boolean {
    const excludedClasses = [
      'tb-checkbox',
      'tb-action-button',
      'tb-link'
    ];
    return excludedClasses.some(cls => target.closest(`.${cls}`));
  }
}
```

| 元素 | 样式 | 行为 |
|------|------|------|
| **← 上一条** | 文字按钮，主色 | 切换到列表上一条实体 |
| **位置指示器** | 文字，灰色 | 显示当前实体在列表中的位置 |

#### 切换交互流程

```typescript
interface EntityNavigation {
  // 切换到上一条
  selectPrevious(): void {
    if (this.currentIndex > 0) {
      this.switchEntity(this.currentIndex - 1);
    }
  }
  
  // 切换到下一条
  selectNext(): void {
    if (this.currentIndex < this.totalCount - 1) {
      this.switchEntity(this.currentIndex + 1);
    }
  }
  
  // 切换实体
  switchEntity(newIndex: number): void {
    // 1. 检查未保存更改
    if (this.hasUnsavedChanges) {
      this.showUnsavedConfirmDialog().then(confirmed => {
        if (confirmed) {
          this.loadEntity(newIndex);
        }
      });
    } else {
      this.loadEntity(newIndex);
    }
  }
  
  // 加载新实体
  loadEntity(index: number): void {
    // 1. 更新选中行高亮
    this.updateSelectedRow(index);
    
    // 2. 内容区域过渡动画
    this.animateContentTransition(() => {
      // 3. 加载新实体数据
      this.fetchEntityDetail(this.entities[index].id);
      
      // 4. 更新位置指示器
      this.updatePositionIndicator(index);
    });
  }
}
```

| **Enter** | 打开选中行详情 | 抽屉关闭时，有选中行 |
| **Tab** | 焦点切换 | 抽屉内元素间切换 |

#### 键盘事件处理

```typescript
interface KeyboardNavigation {
  onKeyDown(event: KeyboardEvent): void {
    // 抽屉打开状态
    if (this.drawerOpen) {
      switch (event.key) {
        case 'ArrowUp':
          event.preventDefault();
          this.selectPrevious();
          break;
        case 'ArrowDown':
          event.preventDefault();
          this.selectNext();
          break;
        case 'Escape':
          event.preventDefault();
          this.closeDrawer();
          break;
      }
    } else {
      // 抽屉关闭状态
      switch (event.key) {
        case 'Enter':
          if (this.focusedRowIndex >= 0) {
            this.openDetailDrawer(this.entities[this.focusedRowIndex]);
          }
          break;
      }
    }
  }
}
```

## 十一、页面选择指南

### 11.1 抽屉 vs 模态框 vs 全屏页面

| 场景 | 抽屉 | 模态框 | 全屏页面 |
|------|------|--------|----------|
| 查看详情 | ✅ 推荐 | ⚠️ 可用 | ❌ 不推荐 |
| 简单编辑（1-5 字段） | ✅ 推荐 | ✅ 推荐 | ❌ 不推荐 |
| 中等编辑（6-15 字段） | ✅ 推荐 | ⚠️ 可用 | ⚠️ 可用 |
| 复杂编辑（15+ 字段） | ⚠️ 可用 | ❌ 不推荐 | ✅ 推荐 |
| 分步向导 | ❌ 不推荐 | ⚠️ 可用 | ✅ 推荐 |
| 需要对比列表数据 | ✅ 推荐 | ❌ 不推荐 | ❌ 不推荐 |
| 需要全屏空间 | ❌ 不推荐 | ❌ 不推荐 | ✅ 推荐 |
| 快速切换多条记录 | ✅ 推荐 | ❌ 不推荐 | ❌ 不推荐 |

## 十二、最佳实践

### 12.1 性能优化

1. **虚拟滚动**：大数据列表使用虚拟滚动
2. **懒加载**：Tab 内容按需加载
3. **防抖搜索**：搜索输入使用 debounce（300ms）
4. **分页加载**：默认每页 10-20 条

### 12.2 可访问性

1. **键盘导航**：所有交互元素支持 Tab 导航
2. **ARIA 标签**：图标按钮必须有 `aria-label`
3. **颜色对比度**：文字对比度 ≥ 4.5:1
4. **焦点指示器**：焦点状态清晰可见

本设计规范基于 ThingsBoard v4.3.x 设计语言，核心特点：

| 特点 | 描述 |
|------|------|
