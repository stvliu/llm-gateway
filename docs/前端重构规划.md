# LLM-Gateway 前端重构规划

> 基于 Indigo 色系设计规范，采用方案C（Ant Design + Tailwind CSS + 自建组件）

---

## 一、重构目标

### 1.1 设计目标

| 目标 | 描述 |
|------|------|
| **视觉统一** | 采用 Indigo 色系，深色侧边栏 |
| **交互优化** | 点击行打开抽屉详情，遮盖式抽屉，实体快速切换 |
| **代码规范** | Tailwind CSS 原子化样式，组件化设计 |
| **主题支持** | 亮色/暗色主题无缝切换 |

### 1.2 技术栈确认

| 技术 | 当前版本 | 目标版本 | 变更 |
|------|----------|----------|------|
| React | 19.0.0 | 19.x | 保持 |
| Ant Design | 6.3.7 | 6.x | 保持 |
| Tailwind CSS | - | 3.x | **新增** |
| TypeScript | 5.8.0 | 5.x | 保持 |
| Zustand | 5.0.0 | 5.x | 保持 |
| React Query | 5.70.0 | 5.x | 保持 |

### 4.3 核心组件接口设计

#### EntityTable

```typescript
interface EntityTableProps<T> {
  // 数据
  dataSource: T[];
  loading?: boolean;
  
  // 列配置
  columns: ColumnConfig[];
  
  // 行标识
  rowKey: string | ((record: T) => string);
  
  // 选中行
  selectedRowId?: string | number;
  
  // 事件
  onRowClick?: (record: T, index: number) => void;
  onSelectionChange?: (selectedKeys: React.Key[]) => void;
  
  // 分页
  pagination?: PaginationConfig | false;
  
  // 批量操作
  batchActions?: BatchAction[];
}

interface ColumnConfig {
  key: string;
  title: string;
  dataIndex?: string;
  width?: number | string;
  sortable?: boolean;
  render?: (value: any, record: any, index: number) => React.ReactNode;
  cellStyleFunction?: (value: any, record: any) => React.CSSProperties;
}

interface PaginationConfig {
  current: number;
  pageSize: number;
  total: number;
  onChange: (page: number, pageSize: number) => void;
}
```

#### EntityDrawer

```typescript
interface EntityDrawerProps<T> {
  // 状态
  open: boolean;
  entity: T | null;
  mode: 'view' | 'edit';
  
  // 导航
  currentIndex?: number;
  totalCount?: number;
  onPrevious?: () => void;
  onNext?: () => void;
  
  // 事件
  onClose: () => void;
  onModeChange?: (mode: 'view' | 'edit') => void;
  onSave?: (entity: T) => Promise<void>;
  onDelete?: (entity: T) => Promise<void>;
  
  // 内容
  tabs?: DrawerTab[];
  defaultTab?: string;
  
  // 加载状态
  loading?: boolean;
  error?: Error | null;
  onRetry?: () => void;
}

interface DrawerTab {
  key: string;
  label: string;
  content: React.ReactNode;
}
```

#### DrawerState Hook

```typescript
interface DrawerState<T> {
  // 状态
  open: boolean;
  entity: T | null;
  mode: 'view' | 'edit';
  hasUnsavedChanges: boolean;
  
  // 方法
  openDrawer: (entity: T) => void;
  closeDrawer: () => void;
  setMode: (mode: 'view' | 'edit') => void;
  setHasUnsavedChanges: (value: boolean) => void;
  
  // 导航
  currentIndex: number;
  totalCount: number;
  navigateTo: (index: number) => void;
}
```

## 五、风险与应对

### 5.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Tailwind 与 Ant Design 样式冲突 | 样式覆盖问题 | 使用 Tailwind 优先，Ant Design 组件级覆盖 |
| 抽屉性能问题 | 频繁切换卡顿 | 使用 React.memo、数据缓存 |
| 暗色主题适配 | 部分组件颜色不对 | 统一使用 CSS 变量 + Tailwind dark: |

### 5.2 进度风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 组件复杂度超预期 | 延期 1-2 天 | 优先核心功能，次要功能后续迭代 |
| 设计规范理解偏差 | 返工 | 先完成一个页面原型，确认后再批量开发 |

## 六、验收标准

### 6.1 功能验收

- [ ] 点击列表行打开抽屉详情
