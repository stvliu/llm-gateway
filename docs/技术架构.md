## 2. gateway-boot 后端模块

### 2.1 技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **语言** | Java | 21 LTS | 支持虚拟线程 |
| **框架** | Spring Boot | 3.5.x | MVC + 虚拟线程 |
| **ORM** | Spring Data JPA | 3.5.x | Hibernate 6.x |
| **数据库** | H2 / MySQL / PostgreSQL | - | H2（默认），兼容 MySQL 5.5+ / PostgreSQL 13+ |
| **缓存** | Redis | 7.x | Redisson 客户端 |
| **安全** | Sa-Token | 1.45.0 | Spring Boot 3 适配 |
| **HTTP 客户端** | OkHttp | 5.3.2 | 同步/异步调用 |
| **可观测性** | OpenTelemetry | 1.47.0 | 链路追踪 |

**分层架构**：采用 COLA Light 5.0 架构，详细分层定义参见 [应用架构.md](./应用架构.md)。

### 2.2 核心组件

| 组件 | 层次 | 说明 |
|------|------|------|
| OpenAIController / AnthropicController | adapter | 请求入口 |
| ProxyService | application | 用例编排 |
| RoutingDomainService | domain/router | 路由选择 |
| ProxyDomainService | domain/proxy | 代理转发 |
| ProxyGateway | domain/proxy | 接口 |
| OpenAIProxyGateway / AnthropicProxyGateway | infrastructure | 实现 |

### 2.3 关键场景实现

#### 代理转发请求

```
请求 → OpenAIController
    → ProxyService.proxy()
        → AuthService.authenticate()           // 认证
        → TokenLimitService.check()            // 限额检查
        → RoutingDomainService.select()        // 路由选择
        → ProxyDomainService.forward()         // 代理转发
            → ProxyGateway.forward()           // 接口
                → OpenAIProxyGateway         // 实现
```

#### 管理操作

```
XxxController → XxxService → XxxDomainService → XxxGateway
```

### 2.4 基础设施组件

| 组件 | 类型 | 说明 |
|------|------|------|
| OkHttpConfig | 配置类 | 连接池、超时 |
| RedisConfig | 配置类 | Redisson 客户端 |
| SaTokenConfig | 配置类 | Sa-Token 安全配置 |
| OpenTelemetryConfig | 配置类 | 链路追踪配置 |
| ProxyGateway | 接口 | 代理转发能力 |
| JpaXxxGateway | 实现 | JPA 持久化 |
| RedisTokenLimitGateway | 实现 | Redis 限流 |

### 2.5 安全机制

| 机制 | 实现 | 说明 |
|------|------|------|
| 认证 | Sa-Token + ApiKeySaTokenDao | API Key → User 映射 |
| 限流 | JVM（Bucket4j）+ Redis 双层 | 标准版/企业版 |
| 脱敏 | MaskingResponseAdvice | 全局响应拦截 |

## 6. 性能优化

### 6.1 连接池

OkHttp 连接池：32 最大连接数，5 分钟空闲存活

### 6.2 虚拟线程

Spring Boot 3.5 + Java 21 天然支持虚拟线程，OkHttp 5.x 支持虚拟线程

### 6.3 缓存策略

| 缓存内容 | TTL |
|---------|-----|

| 用户信息 | 10 分钟 |
| API Key 验证 | 1 分钟 |

## 8. 部署架构

### 8.1 容器化

```dockerfile
# 多阶段构建
FROM maven:3.9-eclipse-temurin-21 AS builder
WORKDIR /app
COPY pom.xml .
COPY src ./src
RUN mvn package -DskipTests

FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
COPY --from=builder /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 8.2 Kubernetes 部署

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-gateway
spec:
  replicas: 3
  template:
    spec:
      containers:
        - name: gateway
          image: llm-gateway:latest
          ports:
            - containerPort: 8080
          resources:
            requests:
              memory: "512Mi"
              cpu: "500m"
            limits:
              memory: "2Gi"
              cpu: "2000m"
```
