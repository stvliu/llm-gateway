## 2. gateway-boot 后端模块

### 2.1 技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **语言** | Java | 21 LTS | 支持虚拟线程 |
| **框架** | Spring Boot | 3.5.x | MVC + 虚拟线程 |
| **ORM** | Spring Data JPA | 3.5.x | Hibernate 6.x |
| **数据库** | H2 / MySQL / PostgreSQL | - | H2（默认），兼容 MySQL 5.5+ / PostgreSQL 13+ |
| **缓存** | Redis | 7.x | Redisson 客户端 |
| **安全** | Sa-Token | 1.45.0 | Spring Boot 3 适配 |
| **HTTP 客户端** | OkHttp | 5.3.2 | 同步/异步调用 |
| **可观测性** | OpenTelemetry | 1.47.0 | 链路追踪 |

### 2.2 分层架构

采用 **COLA Light 5.0 架构**，按业务领域分包：

```
gateway-boot/
└── src/main/java/com/codingas/gateway/
    ├── adapter/                       # 适配器层
    │   ├── chat/                    # OpenAI/Anthropic 兼容端点
    │   ├── model/                   # 模型管理 API
    │   └── admin/                   # 管理后台 API
    ├── application/                   # 应用层
    │   ├── chat/                    # 代理转发用例
    │   ├── auth/                    # 认证用例
    │   └── model/                   # 模型管理用例
    ├── domain/                        # 领域层（7 业务域）
    │   ├── router/                   # 路由域
    │   ├── proxy/                    # 代理域
    │   ├── supply/                   # 模型供给域
    │   ├── security/                 # 安全控制域
    │   ├── quota/                    # 限额配额域
    │   ├── audit/                    # 审计合规域
    │   └── alert/                   # 告警管理域
    ├── infrastructure/                # 基础设施层
    │   └── gateway/                  # Gateway 实现
    └── common/                        # 公共组件
```

### 2.3 核心组件

| 组件 | 层次 | 说明 |
|------|------|------|
| OpenAIController / AnthropicController | adapter | 请求入口 |
| ProxyService | application | 用例编排 |
| RoutingDomainService | domain/router | 路由选择 |
| ProxyDomainService | domain/proxy | 代理转发 |
| ProxyGateway | domain/proxy | 接口 |
| OpenAIProxyGateway / AnthropicProxyGateway | infrastructure | 实现 |

### 2.4 关键场景实现

#### 代理转发请求

```
请求 → OpenAIController
    → ProxyService.proxy()
        → AuthService.authenticate()           // 认证
        → TokenLimitService.check()            // 限额检查
        → RoutingDomainService.select()        // 路由选择
        → ProxyDomainService.forward()         // 代理转发
            → ProxyGateway.forward()           // 接口
                → OpenAIProxyGateway         // 实现
```

#### 管理操作

```
AdminController → XxxService → XxxDomainService → XxxGateway
```

### 2.5 基础设施组件

| 组件 | 类型 | 说明 |
|------|------|------|
| OkHttpConfig | 配置类 | 连接池、超时 |
| RedisConfig | 配置类 | Redisson 客户端 |
| SaTokenConfig | 配置类 | Sa-Token 安全配置 |
| OpenTelemetryConfig | 配置类 | 链路追踪配置 |
| ProxyGateway | 接口 | 代理转发能力 |
| JpaXxxGateway | 实现 | JPA 持久化 |
| RedisTokenLimitGateway | 实现 | Redis 限流 |

### 2.6 安全机制

| 机制 | 实现 | 说明 |
|------|------|------|
| 认证 | Sa-Token + ApiKeySaTokenDao | API Key → User 映射 |
| 限流 | JVM（Bucket4j）+ Redis 双层 | 标准版/企业版 |
| 脱敏 | MaskingResponseAdvice | 全局响应拦截 |

## 6. 部署架构

### 6.1 容器化

```dockerfile
# 多阶段构建
FROM maven:3.9-eclipse-temurin-21 AS builder
WORKDIR /app
COPY pom.xml .
COPY src ./src
RUN mvn package -DskipTests

FROM eclipse-temurin:21-jre-alpine
WORKDIR /app
COPY --from=builder /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 6.2 Kubernetes 部署

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: llm-gateway
spec:
  replicas: 3
  template:
    spec:
      containers:
        - name: gateway
          image: llm-gateway:latest
          ports:
            - containerPort: 8080
          resources:
            requests:
              memory: "512Mi"
              cpu: "500m"
            limits:
              memory: "2Gi"
              cpu: "2000m"
```

## 7. 错误处理

### 7.1 错误码体系

| 错误码 | HTTP 状态 | 说明 |
|--------|----------|------|
| AUTH_001 | 401 | API Key 无效 |
| AUTH_002 | 401 | API Key 已过期 |
| AUTH_003 | 403 | IP 白名单拒绝 |
| QUOTA_001 | 402 | Token 限额超限 |
| QUOTA_002 | 429 | 请求限流超限 |
| MODEL_001 | 404 | 模型不存在 |
| MODEL_002 | 400 | 模型不可用 |
| PROVIDER_429 | 429 | Provider 限流 |
| PROVIDER_401 | 401 | Provider 认证失败 |
| PROVIDER_503 | 503 | Provider 不可用 |
| PROVIDER_TIMEOUT | 504 | Provider 调用超时 |
| PROVIDER_BAD_REQUEST | 400 | Provider 请求错误 |
| PROVIDER_500 | 502 | Provider 内部错误 |
| ROUTER_001 | 503 | 无可用 Provider |
| ROUTER_002 | 500 | 路由策略失败 |

### 7.2 错误响应格式

内部使用时，错误响应包含 Provider 原始信息：

```json
{
  "error": {
    "type": "rate_limit_error",
    "message": "Rate limit exceeded",
    "code": "PROVIDER_429",
    "provider": "openai",
    "raw_code": "insufficient_quota",
    "raw_message": "You exceeded your configured rate limit"
  }
}
```

### 7.3 Provider 错误处理

| Provider 错误 | 处理策略 | 说明 |
|-------------|---------|------|
| 429 Rate Limit | 等待后重试，或切换 Provider/Key | 可重试 |
| 401 Unauthorized | 切换备用 ProviderApiKey | Key 可能失效 |
| 503 Unavailable | 故障转移，切换 Provider | 不可用 |
| 504 Timeout | 重试（按配置次数） | 可能暂时不可用 |
| 400 Bad Request | 不重试，直接返回 | 请求本身错误 |
| 500 Internal Error | 重试/降级 | Provider 内部错误 |

### 7.4 重试策略配置

```yaml
llm:
  retry:
    max-attempts: 3              # 最大重试次数
    retryable-statuses: [429, 503, 504]  #可重试的 HTTP 状态码
    backoff:
      type: exponential          #固定/指数/jitter
      initial-interval: 1s
      multiplier: 2
      max-interval: 30s
```

## 8. 性能优化

### 8.1 连接池

OkHttp 连接池：32 最大连接数，5 分钟空闲存活

### 8.2 虚拟线程

Spring Boot 3.5 + Java 21 天然支持虚拟线程，OkHttp 5.x 支持虚拟线程

### 8.3 缓存策略

| 缓存内容 | TTL |
|---------|-----|
| Provider 列表 | 5 分钟 |
| Model 列表 | 5 分钟 |
| Token 限额 | 1 分钟 |
| 用户信息 | 10 分钟 |
| API Key 验证 | 1 分钟 |
