RoutingContext 设计确认

spec 原文 vs 实际决策 — 请确认以下变更

Spec 原设计
class RoutingContext {
Model model; // 实体引用
Channel channel; // 实体引用
ChannelModel cm; // 实体引用
}

OutboundTuner: ctx.getChannelModel().getUpstreamModelName()
实际决策（推荐）
record RoutingContext(
  ...
String modelName,
String upstreamModelName
) {}

OutboundTuner: ctx.upstreamModelName()
  if null → ctx.modelName()

保持轻量的理由

  • RoutingContext 是值对象，不应持有实体引用
  • Resolver 已查完所有数据，只需传结果
  • Tuner 零 DB 查询、零依赖

对 spec 的影响

  • 更新 RoutingContext 伪代码
  • 更新 OutboundTuner 伪代码
  • 其他部分无需改动
