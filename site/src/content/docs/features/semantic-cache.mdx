# 语义缓存

语义缓存是企业版专属能力，基于向量相似度匹配相似请求并返回缓存结果，可降低成本 30%+。

> ⚠️ **企业版规划功能，当前版本尚未实现。** 以下为设计规格，供评估与规划参考。

## 工作原理

1. 请求到达后，将请求内容向量化（Embedding）
2. 在缓存库中按余弦相似度检索相似请求
3. 相似度超过阈值则直接返回缓存响应，不再调用上游
4. 未命中则正常转发，并将结果写入缓存

## 设计参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 相似度阈值 | 0.95 | 可配置范围 0.80-0.99 |
| 缓存 TTL | 1 小时 | 可按模型配置 |
| 缓存容量 | 10000 条 | - |
| 向量维度 | 1536 | 对应 text-embedding-3-small |
| 用户隔离 | 是 | 不同用户缓存不共享 |
| 流式请求 | 默认跳过 | 可配置 |

## 依赖

- PostgreSQL + pgvector 0.5+（向量存储与检索）
- Embedding 模型（默认 OpenAI text-embedding-3-small）

## 核心能力

- **相似请求返回缓存**：语义级别匹配，降低成本 30%+
- **缓存 TTL 配置**：可设置缓存过期时间
- **缓存命中率统计**：监控缓存效果
- **向量相似度搜索**：基于 pgvector 实现

> 此功能为企业版专属，标准版默认关闭（`semantic-cache: false`）。
