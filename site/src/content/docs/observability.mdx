LLM-Gateway 内建 OpenTelemetry 标准追踪，带 Trace ID 全链路追踪，支持 Prometheus 指标导出。

## 功能清单

| 功能 | 标准版 | 企业版 |
|---|---|---|
| Trace ID（全链路追踪） | ✅ | ✅ |
| 结构化日志（JSON 格式） | ✅ | ✅ |
| 实时指标（延迟/QPS/Token/费用） | ✅ | ✅ |
| Prometheus 导出 | ✅ | ✅ |
| Grafana 仪表盘 | ❌ | ✅ |
| Jaeger 追踪 | ❌ | ✅ |
