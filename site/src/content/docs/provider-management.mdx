LLM-Gateway 支持 50+ 主流大模型供应商的统一接入，提供多 Key 管理、负载均衡与故障转移能力。

## 功能清单

| 功能 | 标准版 | 企业版 |
|---|---|---|
| Provider CRUD（创建/查询/编辑/删除） | ✅ | ✅ |
| 多 Key 管理（自动轮换、调度、故障切换） | ✅ | ✅ |
| 默认 Key 设置（唯一默认 Key，自动清除其他标记） | ✅ | ✅ |
| Key 统计展示（列表页显示活跃数/总数） | ✅ | ✅ |
| 负载均衡（优先级 + 权重） | ✅ | ✅ |
| 渠道分组（按用途/价格分组） | ✅ | ✅ |
| 渠道级故障转移 | ✅ | ✅ |
| 熔断超时（防雪崩） | ✅ | ✅ |
| 代理配置（HTTP/S、Socket5） | ❌ | ✅ |
