# 常见问题

## 调用相关

### 网关 API Key 和上游 Provider Key 有什么区别？

- **网关 API Key**（`sk-` 开头）：签发给调用方，用于调用 `/v1/*` 端点，在 [密钥管理](/apikey-management/) 创建
- **上游 Provider Key**：上游供应商的密钥（如 OpenAI 的 `sk-xxx`），由管理员录入网关，见 [Provider 管理](/provider-management/)

调用方只需持有网关 API Key，无需接触上游密钥。

### 可以用 OpenAI SDK 调用 Anthropic 模型吗？

可以。网关自动完成协议互转，客户端无需特殊参数。详见 [API 调用示例](/api/examples/) 的"协议互转"部分。

### 调用返回 502 / 上游不可用？

网关未配置对应模型的上游 Provider Key，或上游凭证已失效。在管理后台【Provider 管理】检查上游 Key 配置与健康状态。

### 流式响应如何触发？

OpenAI 与 Anthropic 端点均通过请求体 `"stream": true` 触发 SSE 流式响应。

## 部署相关

### 启动时报 ENCRYPTION_KEY_MISSING？

生产环境（非 dev/local profile）必须配置 `GATEWAY_ENCRYPTION_KEY` 环境变量：

```bash
export GATEWAY_ENCRYPTION_KEY="$(openssl rand -base64 32)"
```

详见 [安装部署](/deploy/) 的"加密密钥"部分。

### local profile 重启后数据丢失？

local profile 使用 H2 文件库（`./data/gateway`），数据持久化到文件。但加密密钥若用临时密钥，重启后已加密的上游 Key 无法解密。生产环境请用 PostgreSQL profile 并固定加密密钥。

### 如何切换到 PostgreSQL？

设置 `SPRING_PROFILES_ACTIVE=postgresql` 及 `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` 环境变量，详见 [安装部署](/deploy/)。

## 管理相关

### 忘记了 API Key 明文怎么办？

明文仅创建时返回一次，无法找回。请在 [密钥管理](/apikey-management/) 重新创建 Key 并更新客户端配置，旧 Key 可删除。

### 如何查看 Token 用量？

调用 `GET /api/v1/stats` 查看概览统计。按维度查询的专用端点规划中，详见 [Token 计量与配额](/token-quota/)。
