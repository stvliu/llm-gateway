# 更新日志

本页记录 LLM-Gateway 的版本变更。内部设计文档的变更历史见各自文档末尾。

## 1.0.0-SNAPSHOT

首个可用版本，核心能力：

- **双 API 兼容**：OpenAI（`/v1/chat/completions`）与 Anthropic（`/v1/messages`）端点，支持协议互转
- **Provider 管理**：多厂商上游 Key 资源池，优先级 + 权重负载均衡，多 Key 轮换
- **路由**：模型多渠道配置，FAILOVER / WEIGHTED / RANDOM 路由策略
- **容灾**：应用级 `FAIL_FAST` / `FAIL_RETRY` / `FAIL_OVER` 策略，端点级熔断器，转移事件流
- **安全**：IP 黑名单、API Key 认证、AES-256 加密存储、密钥脱敏
- **可观测性**：OpenTelemetry 追踪、Prometheus 指标、Actuator 健康检查
- **认证**：用户名密码登录、用户管理、调用方 API Key 鉴权

### 已知限制

- OAuth 登录、PII 脱敏执行、内容审核、国密算法：规划中，未实现
- 语义缓存、MCP 协议：企业版规划功能，未实现
- Token 配额扣减：管理 API 已就绪，扣减逻辑尚未接入请求链路
- 多语言 SDK：规划 v2.0，当前使用原生 OpenAI/Anthropic SDK
